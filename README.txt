FlashNextVelocity Studio v1.0.5

Native Strix/Halogen-inspired integration for the existing Gufo Windows runtime:
- context/prompt lookup speculative proposals with exact target verification
- MTP-only and lookup-only acceptance telemetry
- per-position survival and per-depth proposal/verification economics
- configurable Windows physical-RAM + commit-headroom guard
- runtime/config revision checks so stale binaries are rejected

Build/install:
1. Put the project at a short path such as C:\FlashNextVelocity.
2. Run BUILD.bat.
3. Launch with RUN.bat after the validated build completes.

See STRIX-ALLOY-NATIVE-INTEGRATION-README.txt for the integration details and settings.
